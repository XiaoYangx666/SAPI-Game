# Interface: SpawnSafeAreaOptions

- `resetRadius?: Vector3`
- `maintainRadius?: Vector3 | false`
- `clearBlock?: string` — 默认 `minecraft:air`
- `floorBlock?: string` — 默认 `minecraft:bedrock`
- `resetOnAttach?: boolean` — 默认 true
- `protectFloorInteraction?: boolean` — 默认 true
