## 通用组件使用方法

### 组件添加

在 游戏状态(GameState)子类中通过

```ts
this.addComponent(Component, options, tag?:string);
```

来添加组件
下面的**组件参数**部分对应的就是 options 的，没有就不填。

### 组件实例获取

组件添加后，要操作组件，需要获取实例。
方法是:在游戏状态(GameState)或游戏组件(GameComponent)中通过

```ts
this.getComponent(Component,tag?:string)//游戏状态类中
或
this.state.getComponent(Component,tag?:string)//游戏组件类中
```

来获取组件实例，从而操作实例方法

### 组件事件

部分通用组件包含事件，可供订阅，方法和订阅其它事件一样。
但是需要先获取实例。

```ts
const instance=this.state.getComponent(Component,tag?:string)
this.subscribe(instance.xxxEvent,callback,args)
```

## Timer

计时组件，用于实现倒计时。

### [组件参数](../docs/interfaces/TimerOptions.md)

-   `initialTime?: number` - 初始时间（单位：秒）,默认 0
-   `autoStart?: number` - 是否在组件附加后自动开始计时,默认 false
-   `compensate?: boolean`- 是否开启卡顿补偿,默认 false

### [实例属性](../docs/classes/Timer.md#properties)

-   `time: number` - 当前剩余时间
-   `isRunning: boolean` - 正在倒计时
-   `events` - 包含 timer 事件

### [实例方法](../docs/classes/Timer.md#methods)

-   `start()` - 开始计时
-   `stop()` - 停止计时
-   `set(time:number)` - 设置时间

### [组件事件](../docs/classes/Timer.md#events)

-   #### tick 事件

    `instance.events.tick`

    每经过一秒时触发

    ##### 订阅配置

    无

    ##### 事件数据

    -   `remainingTime: number` - 剩余时间

-   #### 2. onTime 事件

    `instance.events.onTime`

    在计时达到指定时间点时触发，可配置是否只执行一次。

    ##### 订阅配置

    ```ts
    {
        time: number;   // 触发的目标时间（秒）
        once?: boolean; // 是否只触发一次（默认 false）
    }
    ```

    ##### 事件数据

    无

### 示例

```ts
export class PKBuildState extends parkourGameModule.State {
    override onEnter(): void {
        //其它代码略
        this.addComponent(Timer, {
            initialTime: this.context.config.buildTime,
            autoStart: true,
            compensate: true,
        }).addComponent(PKBuildDaemonComponent);
        //时间结束就下一阶段
        const timer = this.getComponent(Timer);
        this.subscribe(
            timer.events.onTime,
            () => {
                this.toNextState();
            },
            { time: 0 }
        );
    }
}

export class PKBuildDaemonComponent extends GameComponent<PKBuildState> {
    override onAttach(): void {
        const timer = this.state.getComponent(Timer);
        this.subscribe(timer.events.tick, (t) => {
            this.context.blue.team.actionbar(
                `§b[你是蓝队] §r建筑剩余时间 : §6§l${t.remainingTime}§r 秒`
            );
            this.context.red.team.actionbar(
                `§c[你是红队] §r建筑剩余时间 : §6§l${t.remainingTime}§r 秒`
            );
        });
    }
}
```

## StopWatch

秒表组件，用于记录经过时间，可用于计时或统计游戏中经过的时间。

### [组件参数](../docs/interfaces/StopWatchOptions.md)

-   `initialTime?: number` - 初始时间（单位：秒），默认 0

-   `autoStart?: boolean` - 是否在组件附加后自动开始秒表，默认 false

-   `compensate?: boolean` - 是否开启卡顿补偿（防止掉帧导致时间少算），默认 false

### [实例属性](../docs/classes/StopWatch.md#properties)

-   `time: number` - 当前已计时间（秒）
-   `isRunning: boolean` - 秒表是否正在运行
-   `events` - 包含秒表事件信号对象

### [实例方法](../docs/classes/StopWatch.md#methods)

-   `start()` - 启动秒表

-   `stop()` - 停止秒表

-   `toggle()` - 暂停或恢复秒表

-   `reset(time?: number)` - 重置秒表时间，默认重置为 0

### 组件事件

-   #### tick 事件

    `instance.events.tick`

    每秒触发一次，表示秒表时间增加。

    ##### 订阅配置

    无

    ##### 事件数据

    `elapsedTime: number` - 当前已计时间（秒）

-   #### onTime 事件

    `instance.events.onTime`

    在秒表达到指定时间点时触发，可配置是否只执行一次。

    ##### 订阅配置

    ```ts
    {
        time: number;   // 触发的目标时间（秒）
        once?: boolean; // 是否只触发一次（默认 true）
    }
    ```

    ##### 事件数据

    无

### 示例

```ts
export class DirtShopMainState extends DirtShopMoudle.State {
    protected override onEnter(): void {
        //其它略
        this.addComponent(StopWatch, {
            autoStart: true,
            compensate: true,
        }).addComponent(DirtShopDaemon);
    }
}

export class DirtShopDaemon extends GameComponent<DirtShopMainState> {
    protected override onAttach(): void {
        const stopWatch = this.state.getComponent(StopWatch);
        //时间提醒
        this.subscribe(stopWatch.events.tick, (arg) => {
            if (arg.elapsedTime % 300 == 0) {
                this.context.groupSet.sendMessage(
                    "游戏已开始" + Math.floor(arg.elapsedTime / 60) + "分钟"
                );
            }
        });
    }
}
```

## AutoStopComponent

自动结束组件，用于在指定玩家组集合中所有玩家失效之后自动结束游戏，同时可执行玩家离开回调或释放玩家资源。

### 组件参数

-   `groupSet: PlayerGroupSet<T>` - 需要监控的玩家组集合
-   `onLeave?: (player: T) => void` - 玩家死亡（TTL 为 0）时的回调
-   `onStopGame: () => void` - 所有玩家死亡时触发的游戏结束回调
-   `immediateDie?: boolean` - 是否立即让下线玩家 TTL 归零，默认 false
-   `shouldRelease?: boolean` - 是否自动释放死亡玩家资源，默认 false

### 示例

```ts
export class PillarOfFortuneLobbyState extends PillarOfFortuneModule.State {
    readonly BASE_TIME = 30;

    override onEnter(): void {
        this.addComponent(Timer, { initialTime: this.BASE_TIME });
        //没有玩家自动结束
        this.addComponent(AutoStopComponent, {
            groupSet: new PlayerGroupSet([this.context.players]),
            immediateDie: true,
            onStopGame: () => this.engine.stopGame(),
            onLeave: () => {},
        });
    }
}
```

## LazyLoader

懒加载区块组件，用于在特定维度和坐标的区块加载时动态挂载/卸载游戏组件，从而节省资源。(通常用于常驻 state)

### 组件参数

-   `dimensionId: DimensionIds` - 要检测的维度

-   `pos: Vector3` - 用于检测的区块方块坐标

-   `onLoad: (loader: LazyLoader) => void` - 区块首次加载时触发的回调

-   `onUnload?: () => void`- 区块卸载时触发的回调

-   `interval?: Duration`- 检测间隔，默认 20 tick

### 实例属性

-   `isActive: boolean` - 是否已加载

### 实例方法

-   `reload()` - 手动重新执行加载逻辑：如果当前激活，先触发 onUnload 并清理添加的组件，再执行 onLoad

-   `addComponent(component, options?)` - 在加载逻辑中添加新的组件，并由 LazyLoader 管理组件的生命周期

### 示例

```ts
export class DirtShopLobbyState extends baseModule.State {
    readonly host = new PlayerGroup(GamePlayer);
    readonly attacker = new PlayerGroup(GamePlayer);

    protected override onEnter(): void {
        //使用LazyLoader
        this.addComponent(LazyLoader, {
            pos: { x: 1917, y: -61, z: 1895 },
            dimensionId: DimensionIds.Overworld,
            onLoad: this.onLoad.bind(this),
            onUnload: () => {
                this.host.clear();
                this.attacker.clear();
            },
        });
    }

    onLoad(loader: LazyLoader) {
        loader.addComponent(TeamScoreBoard, {
            //参数略
        });
        loader.addComponent(RegionTeamChooser, {
            //参数略
        });
        loader.addComponent(DirtShopLobbyDaemon);
    }

    start() {
        if (!this.canStartGame()) return;
        const map = this.getMapIndex();
        Game.manager.startGame(DirtShopGame, {
            //参数略
        });
        //重新加载
        this.getComponent(LazyLoader).reload();
    }
}
```

## RespawnComponent

玩家复活组件，用于监听玩家死亡和重生事件，可执行自定义逻辑并选择性广播消息。

### 组件参数

-   `groupSet: PlayerGroupSet<TPlayer>` - 生效的玩家组集合
-   `onDie?: (player: TPlayer, group: PlayerGroup<TPlayer>, source?: Entity) => void`
    玩家死亡时触发的自定义逻辑
-   `onSpawn?: (player: TPlayer, group: PlayerGroup<TPlayer, TData>) => void`
    玩家重生时触发的回调
-   `autoBroadcast?: boolean` - 是否自动广播消息，默认 false
-   `buildNameFunc?: (player: TPlayer, group: PlayerGroup<TPlayer, TData>) => string`
    构建玩家显示名，用于广播消息
-   `buildMsg?: (playerName: string, killerName: string | undefined, player: TPlayer) => string`
    自定义死亡消息构建

### 示例

```ts
this.addComponent(RespawnComponent<BlockedInCombatPlayer, BlockedTeamData>, {
    groupSet: this.context.groupSet,
    onDie(player) {
        if (player.live > 0) {
            player.live--;
        }
        if (player.live <= 0) {
            player.player?.setGameMode(GameMode.Spectator);
        }
    },
    autoBroadcast: true,
    buildNameFunc(player, group) {
        return `${BlockedTeamColorMap[group.data.color].color}${player.name}`;
    },
    buildMsg(playerName, killerName, player) {
        return killerName
            ? `${playerName} §r 被 ${killerName} §r 杀死了 (剩余 ${player.live} 命)`
            : `${playerName} §r 死了 (剩余 ${player.live} 命)`;
    },
});
```

## SpawnPointProtector

出生点保护组件，用于为指定玩家组设置重生点，并循环保护出生点区域不被破坏或交互。

### 组件参数

-   `playerGroup: PlayerGroup<P>` - 需要保护的玩家组
-   `spawnPoint: Vector3` - 出生点坐标
-   `dimension: Dimension` - 出生点所在维度
-   `autoSetSpawnPoint?: boolean` - 是否循环设置玩家重生点，默认 true
-   `protectInterval?: Duration` - 循环保护出生点区域的间隔，默认 10 tick
-   `protectRadius?: Vector3` - 出生点保护范围，默认 1x1x1

### 实例方法

-   `setPlayerSpawnPoints()` - 手动设置所有玩家的重生点
-   `teleportAllToSpawn()` - 将所有玩家传送到出生点

## BlockInteractionBlocker

通用方块交互阻止组件，用于限制指定玩家组与特定方块或方块组件的交互，可选择显示提示信息。

### 组件参数

-   `groupSet: PlayerGroupSet` - 被限制的玩家组
-   `blockIds?: string[]` - 可选，要阻止交互的方块 ID 列表，未设置或为空表示不按 ID 限制
-   `blockComponentType?: BlockComponentTypes` - 可选，要阻止交互的方块组件类型，未设置表示不按组件过滤
-   `showMessage?: boolean` - 可选，是否给玩家提示，默认 true
-   `message?: string` - 可选，提示信息，默认 `"§c你无法与该方块交互！"`

## EntityInteractionBlocker

通用实体交互阻止组件，用于限制指定玩家组与特定实体或实体组件的交互，可选择显示提示信息。

-   `showMessage?: boolean` - 可选，是否给玩家提示，默认 true

## RegionProtector

区域保护组件，用于阻止指定区域内或区域外的方块被破坏或交互，可限定特定玩家组生效。

### 组件参数

-   `region: GameRegion` - 需要保护的区域
-   `blockBreakInside?: boolean` - 是否阻止区域内方块被破坏
-   `blockInteractInside?: boolean` - 是否阻止区域内方块被交互
-   `blockBreakOutside?: boolean` - 是否阻止区域外方块被破坏
-   `blockInteractOutside?: boolean` - 是否阻止区域外方块被交互
-   `groupSet?: PlayerGroupSet<any>` - 生效的玩家组集合（未指定则对所有玩家生效）

### 示例

```ts
this.addComponent(RegionProtector, {
    region: this.context.map.region,
    blockBreakOutside: true,
    blockInteractOutside: true,
    groupSet: this.context.groupSet,
});
```

## RegionTeamChooser

区域队伍选择器组件，用于在指定区域内自动将玩家加入队伍，并可在进入或首次加入时触发回调。

### 组件参数

-   `config: RegionTeamChooserData<P>[]` - 区域队伍配置数组，每个元素描述一个区域和对应队伍的规则

    -   `region: GameRegion` - 区域
    -   `team: PlayerGroup<P>` - 区域对应的队伍
    -   `onEnter?: (player: P) => void` - 玩家进入区域时触发
    -   `onJoin?: (player: P) => void` - 玩家首次加入本队伍时触发

-   `removeOnLeave?: boolean` - 玩家离开区域时是否从队伍中移除，默认 false
-   `allowSpectator?: boolean` - 是否允许旁观者加入队伍，默认 false

### 示例

```ts
export class CvSBackState extends baseModule.State {
    readonly chicken = new PlayerGroup(GamePlayer);
    readonly shepherd = new PlayerGroup(GamePlayer);

    override onEnter(): void {
        //队伍选择
        this.addComponent(LazyLoader, {
            onLoad: this.onLoad.bind(this),
            onUnload: () => {
                this.chicken.clear();
                this.shepherd.clear();
            },
            dimensionId: DimensionIds.Overworld,
            pos: { x: 34, y: -61, z: 49 },
        });
    }

    onLoad(loader: LazyLoader) {
        //其它略
        loader.addComponent(RegionTeamChooser, {
            config: [
                {
                    team: this.chicken,
                    region: new CubeRegion(
                        DimensionIds.Overworld,
                        { x: 38, y: -61, z: 61 },
                        { x: 36, y: -59, z: 59 }
                    ),
                    onJoin: (p) => {
                        p.sendMessage("§c你加入了小鸡队伍");
                    },
                },
                {
                    team: this.shepherd,
                    region: new CubeRegion(
                        DimensionIds.Overworld,
                        { x: 32, y: -61, z: 61 },
                        { x: 30, y: -59, z: 59 }
                    ),
                    onJoin: (p) => {
                        p.sendMessage("§b你加入了猎人队伍");
                    },
                },
            ],
        });
    }
}
```

## TeamScoreBoard

队伍计分板组件，用于在侧边栏显示多个队伍的玩家列表，可自定义排序、过滤及名称显示方式。

-   `scoreboardName: string` - 计分板内部名称
-   `displayName: string` - 计分板显示名称
-   `teams: TeamScoreBoardTeamData<P>[]` - 队伍数据数组

    -   `team: PlayerGroup<P>` - 队伍对象
    -   `prefix?: string` - 玩家名前缀
    -   `buildName?: (player: P) => string` - 自定义名称方法，会覆盖 `prefix`
    -   `teamSort?: (p1: P, p2: P) => number` - 队伍内部排序方法
    -   `teamFilter?: (p: P) => boolean` - 队伍内部过滤函数

-   `show()` - 将计分板显示在侧边栏
-   `refreshScoreBoard()` - 刷新计分板内容，根据 `teams` 配置生成玩家列表

### 示例

```ts
loader.addComponent(TeamScoreBoard, {
```

## InfoScoreboard

信息侧边栏组件，用于显示自定义计分板信息，可动态更新内容。

### 组件参数

-   `scoreBoardName: string` - 计分板内部名称
-   `displayName: string` - 计分板显示名称
-   `paddingLeft?: number` - 内容左侧边距（空格数），默认 0
-   `header?: () => string[]` - 计分板顶部显示内容
-   `footer?: () => string[]` - 计分板底部显示内容
-   `showOnAttach: boolean` - 是否在组件附加时立即显示计分板

### 实例方法

-   `show()` - 手动显示计分板在侧边栏
-   `updateLines(lines: string[])` - 更新计分板内容，可自动添加 header、footer 和左侧 padding

### 示例

```ts
export class PillarOfFortuneMainState extends PillarOfFortuneModule.State {
    override onEnter(): void {
        this.addComponent(InfoScoreboard, {
            scoreBoardName: "pillarOfForture_" + this.engine.key,
            displayName: "§a§l幸运之柱",
            showOnAttach: true,
            paddingLeft: 2,
            header: () => ["§7" + getFormattedTime()],
            footer: () => ["§d§lPartyGames"],
        }).addComponent(PillarOfFortuneDaemon);
        //其它代码略
    }
}

export class PillarOfFortuneDaemon extends GameComponent<PillarOfFortuneMainState> {
    override onAttach(): void {
        const timer = this.state.getComponent(Timer);
        this.subscribe(timer.events.tick, (t) => {
            this.updateSidebar(t.remainingTime);
        });
```
